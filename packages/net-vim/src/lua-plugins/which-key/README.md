# which-key.nvim (vendored)

Vendored from https://github.com/folke/which-key.nvim at tag `v3.17.0`
(MIT licensed, see `LICENSE`).

These files are shipped as-is (byte-for-byte) and loaded through Net-Vim's
Lua module loader as `require("which-key")` from `.config/net-vim/lua/which-key/`.

Removed (not needed for Net-Vim): `docs.lua`, `extras.lua`, `health.lua`,
`migrate.lua` and the `plugin/which-key.lua` auto-setup entry (Net-Vim loads
plugins explicitly from `init.lua`).
